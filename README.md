# Hi, I'm Arturo 👋 
### Data Analyst & Analytics Engineer

I build end-to-end data pipelines, modern data warehouse architectures, and business intelligence dashboards that turn complex raw data into actionable decision-making tools.

---

### 🚀 What I Do:
- 📊 **Data Modeling & Warehousing:** Designing scalable schemas, staging/marts layers (Medallion architecture), and analytical views in Google BigQuery & PostgreSQL.
- ⚙️ **ETL / ELT Pipelines:** Automating data ingestion, API integrations, and transformations using Python (Pandas), SQL, and Docker.
- 📈 **Business Intelligence:** Crafting interactive, decision-driven dashboards and reports in Looker Studio and Power BI.
